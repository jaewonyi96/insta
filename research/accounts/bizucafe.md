# @bizucafe — BZCF | 비즈까페

> **한 줄 요약**: 익명의 '주인장'이 흥미로운 비즈니스 아티클과 뉴스를 골라 자기 코멘트를 붙이는 비즈니스 큐레이션 브랜드입니다. 인스타그램은 유튜브·스레드·텔레그램·뉴스레터·페이스북으로 이어지는 여러 창구 가운데 하나입니다. **게시물 262개로 약 8만 팔로워**를 모았습니다. 적게 올리지만 한 편마다 많이 모으는 계정입니다.

- 작성·검증일: 2026-09-30
- **검증 방식과 한계**: 이 문서는 1차 조사 결과를 반대 입장에서 다시 검증한 결과입니다. 다만 검증 단계에서는 세션의 웹 검색 한도(200회)가 이미 소진돼 **새 검색을 한 건도 하지 못했습니다.** 인스타그램·bzcf.io·스레드 직접 열람도 네트워크 정책(프록시 403)으로 막혔습니다. 그래서 아래 네 가지로 교차 확인했습니다.
  1. 1차 조사자가 모은 검색 결과 제목과 URL
  2. 같은 세션의 다른 조사가 독립적으로 모은 수치([research/landscape.md](../landscape.md))
  3. 사용자가 제공한 스크린샷
  4. URL·게시물 ID 디코딩과 산술 검산
- 확인 강도는 '신뢰도' 열과 맨 아래 '검증 결과' 표에 적었습니다. **중요한 결정 전에는 앱에서 직접 재확인하기를 권합니다.**

**어느 숫자가 가장 최신인가?** 사용자 스냅샷(약 8만, 게시물 262개)입니다. 근거는 두 가지입니다.
1. 게시물 수는 삭제하지 않는 한 줄지 않습니다. 세 관측값이 138(숏트렌드) → 242(검색 스니펫) → 262(사용자) 순서로 맞물리고, 팔로워도 4.8만 → 4.96만 → 7만 → 8만으로 같은 방향입니다.

단, 스크린샷의 출처와 촬영 시각은 표시돼 있지 않아 신뢰도는 '중간'으로 둡니다.

## 운영 주체와 연혁

### 운영 주체
- **실명은 확인하지 못했습니다.** 운영자는 스스로를 '주인장'이라 부르는 익명 페르소나를 씁니다. 근거는 다음과 같습니다.
  - High Output Club 블로그 글 제목 '유튜브 비즈까페(BZCF) 주인장이 말하는 좋은 콘텐츠'([HOC](https://blog.highoutputclub.com/hoc-membershiptalk-bzcf/))
  - 페이스북 페이지 핸들 `bizucafejuin`(비즈까페 주인)([FB](https://www.facebook.com/bizucafejuin/))
- **PUBLY 프로필의 설명**([publy.co/profile/670](https://publy.co/profile/670)): 외국계 회사 서울 오피스에 다니며 매일 비즈니스 아티클을 큐레이션하고 코멘트를 단다고 적혀 있습니다. 다만 작성 시점이 표시돼 있지 않고, PUBLY 활동기에 쓴 설명일 가능성이 커 **현재 직업 정보로 쓰기에는 낡았을 수 있습니다.**
- **'1인 운영'은 확인된 사실이 아닙니다.** 페르소나가 한 명이라는 점만 확인했고, 팀 규모는 모릅니다.
- **링크드인 `bzcf-lead`의 성격**: `linkedin.com/posts/bzcf-lead_...` 형태의 URL은 회사 페이지와 개인 프로필이 같은 모양이라, 회사 페이지로 단정할 수 없습니다.
- **추가 발견(1차 조사 누락)**: 인스타 매거진 광고 네트워크 **애딧(Adit, 애딧앤아크)이 2026년 8월 시드 투자를 받을 때 카카오벤처스·매쉬업벤처스·베이스벤처스와 함께 '비즈까페(BZCF)'가 투자자로 참여**했다는 보도가 있습니다([플래텀](https://platum.kr/archives/291850), landscape.md 조사 인용, 이번 검증에서는 원문 재확인 못 함).
  - 이것은 BZCF가 단순한 콘텐츠 계정을 넘어 **투자 주체이자 업계 네트워크 노드**로 활동한다는 신호입니다.
  - 법인 투자인지 운영자 개인의 엔젤 투자인지는 확인하지 못했습니다.
- 법인명과 사업자 정보는 찾지 못했습니다.

- 운영자 실명·경력·전업 여부, 팀 규모, 법인·사업자 정보. 애딧 투자가 법인 투자인지 개인 투자인지.

- 인스타그램 포맷 비율(캐러셀·릴스·단일 이미지), 카드 템플릿(색상·폰트·인물 사진 사용), 캡션 길이·이모지·해시태그 패턴.
- 인스타그램 주간 발행 빈도, 최근 성장 속도(관측 날짜가 없어 계산 불가).
