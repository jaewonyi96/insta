> 작성 기준일: 2026-09-30 · 조사 방법: 웹 검색 결과(제목·요약·스니펫) 기반. WebFetch가 차단되어 원문 전체를 열람하지 못한 출처가 많으므로, 숫자는 모두 "출처가 그렇게 주장한다" 수준으로 읽고 중요한 의사결정 전에는 원문을 한 번 더 확인할 것.

## 1. 알고리즘·정책

### 1-1. 랭킹 신호 (Mosseri 공식 발언)
- **3대 신호 = 시청 시간(watch time), 도달 대비 좋아요(likes per reach), 도달 대비 공유/보내기(sends per reach).** 2025년 1월 Adam Mosseri가 직접 언급. "좋아요는 팔로워(연결된 콘텐츠)에게, 보내기(DM 공유)는 비팔로워(비연결 콘텐츠) 도달에 약간 더 중요하다"는 취지. [공식 발언, 보도 경유] (Social Media Today 2025-01-22 보도를 인용한 dataslayer, blckalpaca)
- 시청 시간은 3초 조회 같은 문턱이 아니라 **리플레이 포함 총 재생 시간**으로 계산된다는 설명이 여러 가이드에 있음. [3자]
- "DM 공유가 좋아요보다 3~5배 가중치"라는 수치가 널리 돌지만 **Instagram 공식 수치가 아님**. [3자] (socialday.live 등)
- 매거진 계정에 주는 시사점: 카드뉴스의 KPI는 좋아요가 아니라 **저장·공유(보내기)·끝까지 넘김(스와이프 완료)**. "친구에게 보내고 싶은" 정보(체크리스트, 비교표, 요약본)가 확산의 엔진.

### 1-2. 독창성(Originality) 정책 — 큐레이션 계정에 가장 중요
- **2026-04-30: 무독창 애그리게이터 제재를 사진·캐러셀로 확대.** 자기가 만들지 않은 콘텐츠를 반복 리포스트하거나 주로 남의 작업을 사진·캐러셀로 올리는 계정은 앱 전반의 **추천(비팔로워 노출) 대상에서 제외**. 기존엔 릴스에만 적용되던 보호 장치를 사진·캐러셀로 넓힌 것. 팔로워 피드에는 계속 노출됨. [보도] (TechCrunch 2026-04-30, Tubefilter 2026-04-30)
- **Instagram의 '오리지널' 정의**: 직접 만들었거나 "실질적으로 변형(materially altered)"한 콘텐츠. 새로운 해설·유머를 더한 밈 같은 변형 저작물 포함. **가이드·스토리텔링 형식의 직접 디자인한 시각 콘텐츠도 오리지널로 인정.** [공식] (creators.instagram.com Original Content Guidelines, TechCrunch)
- **오리지널로 인정되지 않는 것**: 테두리·워터마크 추가, 속도 변경, 보이는 내용을 설명만 하는 캡션, 같은 언어 자막, 스티커·GIF만 얹기, **출처를 적어도 남의 게시물 스크린샷을 올리는 것**. 실용 테스트: "내 기여를 빼도 콘텐츠가 거의 그대로면 오리지널이 아니다." [공식 가이드 요약] (creators.instagram.com, ALM Corp, Launchvibes)
- **복구 조건**: 최근 30일(롤링) 동안 올린 사진·캐러셀·릴스의 대부분이 오리지널이면 다시 추천 대상이 됨. 설정 > **계정 상태(Account Status)**에서 추천 가능 여부 확인. [공식 가이드 요약]
- "30일 내 리포스트 10건 이상이면 추천 전면 제외", "애그리게이터 도달 60~80% 하락/오리지널 40~60% 상승" 같은 수치는 **3자 블로그 주장**이며 공식 확인 불가. [3자] (versely.studio, launchvibes)
- 남의 콘텐츠를 소개해야 할 때는 **네이티브 리포스트 버튼(2025-08-06 출시, 원작자 자동 크레딧, 별도 '리포스트' 탭에 표시)** 또는 **콜라보(공동 작업자) 태그**를 쓰라는 것이 Instagram 권장. [보도/공식 가이드]
- 타 플랫폼 워터마크(TikTok, CapCut 로고 등)가 있는 콘텐츠는 추천에서 걸러진다는 권고가 반복적으로 등장. [3자 다수]
- **이 정책이 AI·비즈니스·경제 큐레이션 계정에 의미하는 것**: 기사 캡처·트윗 캡처·타 계정 이미지 재업로드 위주면 추천이 끊긴다. 반대로 "내가 다시 쓴 요약 + 나만의 관점/해설 + 직접 만든 도표·디자인"은 오리지널로 인정받는 구조. 벤치마크 계정들처럼 **자체 디자인 템플릿 + 에디터 해설**이 필수.

### 1-3. 포맷별 도달 특성
- **캐러셀**: 최대 **20장**(2024-08 10장→20장 확대). 사용자가 첫 장에서 넘기지 않으면 **두 번째 장으로 다시 보여주는 "두 번째 기회"**가 있다고 Mosseri가 설명. [공식 발언, 보도] (The Daily Star, Matt Navarra Threads 인용)
- **음악을 넣은 사진·캐러셀은 릴스 탭 노출 대상** (2024-10 @creators 공지, 이후 재공지) → 비팔로워 도달 확대 수단. 음악은 모바일 앱에서만 추가 가능, 게시 후 변경 불가라는 설명. [공식] (@creators Threads, Lindsey Gamble)
- 2026년에는 게시 후 슬라이드 순서 변경·삭제가 가능해졌다는 설명이 있음. [3자] (metricool)
- **참여율 벤치마크**: Socialinsider 2026 벤치마크 기준 캐러셀 약 0.55%, 릴스 0.48~0.52%(인용처마다 다름), 단일 이미지는 전년 대비 약 17% 하락. "캐러셀은 기존 팔로워와 저장·권위, 릴스는 신규 유입" 이라는 해석이 일반적. [3자 데이터] (socialinsider.io)
- **비율**: 프로필 그리드가 3:4 세로형으로 바뀌어 **1080×1440(3:4)** 또는 **1080×1350(4:5)** 권장. 1:1(1080×1080)은 그리드에서 잘림. [3자 다수] (Buffer, Oktopost, influencermarketinghub)
- **릴스 길이**: 2025-01 최대 3분 지원 발표, "여전히 숏폼 중심"이라고 Mosseri 언급. [공식] (Mosseri Threads) 3분 초과 릴스는 비팔로워 추천에서 불리하다는 주장. [3자]

### 1-4. Trial Reels(체험 릴스)
- 2024-12 출시. **팔로워에게 보여주기 전에 비팔로워에게 먼저 테스트**하고, 성과가 좋으면 수동/자동으로 팔로워에게 공개. 체험 중에는 프로필 그리드·해시태그 페이지에서 제외. 프로페셔널 계정 전용. [공식] (about.fb.com 2024-12, creators.instagram.com)
- 예약 게시 지원, "사용 크리에이터 40%가 게시 빈도 증가", "비팔로워 릴스 도달 80% 증가" 등은 3자 가이드가 전한 수치. 2026년 초 팔로워 1,000명 이상 프로 계정으로 확대됐다는 설명도 3자 출처. [3자] (Social Media Today, storrito, postfa.st)
- 활용법: 매거진 계정은 같은 주제를 "훅만 다르게" 2~3개 체험 릴스로 돌려 이긴 훅을 카드뉴스 표지 카피로 재사용.

### 1-5. Edits 앱
- Meta의 독립 숏폼 편집 앱, **2025-04-22 출시**. 템플릿, 텔레프롬프터, 자막·텍스트 스타일, 브랜드 컬러, 분석 등. [보도] (Wikipedia, Inro)
- 2026 업데이트: 1월 IG 계정/릴스 링크 삽입·주간 아이디어·신규 효과 25종, 6월 영감 탭 내 릴스 검색·프로젝트 버전, 8월 자막 자동 하이라이트·프리즈 프레임 등. [보도] (Music Ally 2026-01-16, Social Media Today, SocialBee)
- 장점: **타 플랫폼 워터마크가 없음** → 독창성·추천 리스크 감소.

### 1-6. 해시태그·검색
- **게시물당 해시태그 최대 5개**(2025-12 발표). Mosseri: 해시태그는 도달을 늘리지 않으며 "게시물이 무엇에 관한 것인지 알리는 라벨". [공식 발언, 보도] (Digital Trends, Social Media Today)
- **2025-07-10부터 만 18세 이상 공개 프로페셔널 계정의 게시물이 Google·Bing 검색에 색인** 가능(설정에서 해제 가능). 캡션 첫 줄·대체텍스트가 검색 제목처럼 작동 → 캡션 첫 줄에 핵심 키워드(예: "엔비디아 실적 요약", "청년도약계좌 비교"). [보도] (ppc.land, SEOZoom)

### 1-7. 기타 2025–2026 변화
- **Mosseri 2025-12-31 연말 메모(20장 캐러셀)**: "진정성(authenticity)이 무한히 복제 가능해지고 있다" — AI가 무엇이든 만들 수 있으니, 누가·왜 올렸는지(맥락·출처·신원)가 중요해진다는 메시지. 다듬어진 미감보다 날것의 인간적 관점 강조. [공식 발언, 보도] (Mosseri Threads, om.co, Social Media Today)
- **"Your Algorithm"(내 알고리즘) 토픽 제어**: 2025-12 미국 릴스에서 시작, 2026-01 영어권 확대, 2026-04 탐색 탭, 이후 메인 피드로 확대 보도. 사용자가 관심 토픽을 직접 추가·삭제. 한국어 지원 시점은 **미확인**. → 토픽이 선명한 니치 계정이 유리. [보도] (about.instagram.com, Fox News, Buffer)
- **인사이트 지표**: 공유율·건너뛰기율(skip rate, 2025-08 릴스 인사이트 추가), 리포스트 수, 시간 경과별 조회 등 추가. [3자/보도] (Social Media Today, Inro)
- **네이티브 예약**: 앱·Meta Business Suite에서 최대 75일 전, 하루 25건까지 예약(스토리는 불가로 안내). [3자]

## 2. 포맷 베스트 프랙티스

### 2-1. 카드뉴스(캐러셀) 설계
| 요소 | 권장 | 근거 |
|---|---|---|
| 장수 | 일반 정보형 **7~10장**, 심층 가이드·케이스 스터디 12~20장. "5장 미만은 짧은 글, 10장 초과는 중간 이탈"이라는 주장과 "5~8장이 저장·완독 최고"라는 주장이 공존 | [3자] metricool, carouselli, TrueFuture Media |
| 구성 | 표지(1) + 본문(2~10) + 마지막 장(1)이 한국 카드뉴스 표준. 첫 장=표지, 뒷장=본문, **캡션=기사 본문** 겸용 | pixso, PAP MAGAZINE |
| 첫 장(표지) | "스와이프해야 답을 알 수 있는" 정보 공백을 만드는 구체적 훅 + 강한 시각 대비. Instagram도 "첫 장에 텍스트를 넣으라"고 팁 제시 | [3자]/[공식 팁] adpicto, @creators |
| 두 번째 장 | 미스와이프 시 2번 장이 재노출되므로 **2번 장도 독립 훅**(요약 한 줄/핵심 숫자) | [공식 발언] Mosseri |
| 장당 텍스트 | "한 장에 한 메시지": 번호 + 짧은 헤드라인 + 짧은 설명 | [3자] metricool |
| 폰트 | 1~2종(최대 3종), 본문은 고딕·명조, 장식 폰트는 제목에만 | ampm 인사이드 |
| 비율 | 1080×1440(3:4) 또는 1080×1350(4:5) | [3자] |
| 마지막 장 | 저장·공유 유도("저장해두고 ○○ 때 꺼내보세요", "이 소식 알아야 할 친구에게 보내기") + 다음 호 예고/시리즈명 + 뉴스레터·키워드 CTA | wepick, 한국 가이드 |
| 음악 | 사진 캐러셀에 음악 추가 시 릴스 탭 노출 대상 | [공식] @creators |

- 매거진 계정다움은 **템플릿 일관성**에서 나온다: 표지 레이아웃·컬러·로고 위치·시리즈명 고정(예: 브랜더쿠는 시그니처 블루를 인스타 프로필·하이라이트·뉴스레터 CTA까지 통일). [보도] (스티비 블로그)
- 리소스가 적게 드는 포맷(단신 요약)과 많이 드는 포맷(심층 분석)을 **교차 발행**하면 지속 가능. [3자] (insight-er)
- 텍스트힙 트렌드: 글을 읽는 것을 "멋있다"고 여기는 흐름 속에 인스타 매거진이 늘어남 — 긴 캡션과 텍스트 위주 카드가 약점이 아님. [보도] (스티비 블로그, GQ Korea 2024, 고구마팜)

### 2-2. 뉴스 큐레이션 릴스
- 첫 1~3초 훅(놀라운 숫자, 반전 질문, 결론 먼저). "시청자 최대 50%가 3초 안에 이탈"이라는 주장. [3자] (tilnote)
- **화면 자막 필수**(무음 시청), 자체 보이스오버/오리지널 오디오 비중 확대 권장. [3자]
- 3분 이하 유지(비팔로워 추천), 타 플랫폼 워터마크 금지, 가능하면 Edits로 편집. 
- 카드뉴스를 그대로 슬라이드쇼 릴스로 재가공 + Trial Reels로 훅 테스트.

### 2-3. 캡션·CTA
- **캡션 첫 줄 = 검색 제목**(구글 색인 대상). 핵심 키워드 + 호기심 한 줄.
- 해시태그 3~5개, 주제 라벨 용도로만.
- 참여 CTA는 하나만: 저장 / 공유(보내기) / 댓글 키워드(→DM 자동화) 중 게시물 목적에 맞게 선택.
- 광고 게시물은 캡션 첫 줄(더보기 이전)과 이미지 내에 광고 표시(→ 5장 참조).

## 3. 성장 전술

### 3-1. 게시 빈도·일관성
- Buffer(10만 계정·200만+ 게시물 분석): 주 1~2회 → **주 3~5회로 늘리면 팔로워 성장률이 2배 이상**, 게시물당 도달도 약 12% 증가. 6~9회 이상도 더 늘지만 체감 효과 감소. 스토리 제외 기준. [3자 데이터] (Buffer, Social Media Today)

## 7. 핵심 요약

1. **이제 "큐레이션"만으로는 추천을 못 받는다.** 2026-04-30부터 무독창 애그리게이터 제재가 사진·캐러셀까지 확대됐다. 기사·트윗·타 계정 캡처 재업로드는 금지 수준으로 피하고, "사실 추출 → 내 문장 재작성 → 내 해설·프레임 → 직접 만든 디자인·도표"로 만들어야 오리지널로 인정되고 저작권 리스크도 동시에 줄어든다.
2. **KPI는 좋아요가 아니라 보내기(DM 공유)·저장·시청 시간**이다. 친구에게 보낼 만한 비교표·체크리스트·"3줄 요약"과, 끝까지 넘기게 만드는 스토리 구조(표지 훅 → 2번 장 재훅 → 마지막 장 저장·공유 CTA)를 설계할 것.
3. **포맷 믹스**: 캐러셀(7~10장, 3:4, 시리즈 템플릿)로 권위·저장을 쌓고, 음악 추가 캐러셀과 3분 이하 릴스(Trial Reels로 훅 테스트, Edits로 워터마크 없이 편집)로 비팔로워를 데려온다.
4. **주 3~5회 + 요일별 고정 코너 + 콜라보 + 스레드 병행**이 초기 성장의 기본기다. 0→1천 구간에선 비슷한 규모 주제 계정과의 콜라보를 반복한다.
5. **퍼널**: 인스타(발견) → 댓글 키워드 DM(리드) → 뉴스레터(소유 채널) → 광고·리포트·강의. 플랫폼 정책 리스크에 대비하는 보험이기도 하다.
6. **수익 단가는 출처마다 편차가 크다**(1만~10만 팔로워 게시물 30만~100만원 수준 주장부터 10만+ 계정 피드 500만원+ 주장까지). 매거진은 "제작 + 게재 + 뉴스레터 번들" 패키지로 가격을 설계하고, 카드뉴스 제작 대행 시세(10장 약 15만원)를 하한선으로 삼을 것.
7. **법 체크 3종**: ① 광고는 이미지 안 + 캡션 첫 줄에 한국어로 표시하고 유료 파트너십 레이블 사용(더보기 안 숨김 금지), ② 뉴스 사진·캡처는 쓰지 말고 제목+링크·사실 재작성, ③ 수익이 반복되면 사업자등록(940306/921505), 직접 판매는 통신판매업(면제 기준: 50회 미만/간이과세) 확인. AI 기본법 표시 의무는 크리에이터가 아닌 AI사업자 대상이지만, Meta의 사실적 AI 콘텐츠 표시 정책은 적용된다.
