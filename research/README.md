## 1. 방법과 한계

### 1-1. 어떻게 조사했나
- **웹 검색(WebSearch)만 썼습니다.** 인스타그램·스레드 검색 결과의 **제목**에는 캡션 첫 줄과 바이오가 들어 있어서, 이것을 주 자료로 썼습니다. 여기에 채용공고, 기사, 제3자 분석 페이지(Adit Lens 등)를 더해 교차 확인했습니다.
- **게시 시각 계산**: 인스타그램·스레드 게시물 주소의 코드(shortcode)를 풀면 올린 시각이 나옵니다. 이 방법으로 게시 시각(KST)과 요일을 계산했고, 날짜를 아는 게시물로 검산했습니다.
- **사용자 표(스크린샷)**를 가장 최신 관측값으로 반영했습니다. 다만 에크케 40.4만처럼 웹에서 다시 확인되지 않는 값은 그렇게 표시했습니다.
- 계정 프로필은 세 번 손봤습니다.
  1. 1차 조사
  2. 반대 입장 검증(검색 없이 로컬 파일 대조). 이때 **다른 계정의 게시물이 섞여 있던 것을 모두 뺐습니다**(3-2 참고).
  3. **2026-09-30 검색 기반 재검증.** 계정마다 WebSearch로 수치, 운영 주체, 게시물 귀속, 훅 문구를 다시 확인했습니다(합계 155회: AI Freaks 48, BZCF 39, 로만 25, 에크케 43). 바뀐 내용은 3-3에 모았습니다.

### 1-2. 한계
1. **인스타그램에 직접 접속하지 못했습니다.** instagram.com은 네트워크 정책으로 막혀 있습니다(403). 그래서 **이미지 속 글자(표지 문구), 장 구성, 색, 폰트, 로고는 네 계정 모두 한 장도 보지 못했습니다.** 시각 스타일은 전부 미확인입니다.
2. **계정 사실은 2026-09-30에 웹 검색으로 다시 검증했습니다.** 반대 입장 검증 라운드는 검색 한도 때문에 새 검색이 0건이었습니다. 그 뒤 계정별 재검증에서 WebSearch를 합계 155회 썼습니다(AI Freaks 48, BZCF 39, 로만 25, 에크케 43. 도메인 제한 오류로 결과가 없던 호출 포함).
   - 확인 수준은 **검색 결과 제목, 스니펫, URL 슬러그, 검색 도구의 요약문**까지입니다. 페이지를 직접 열지는 못했습니다.
   - 요약문에만 나온 내용은 계정 파일에서 '검색 요약'으로 표시하고 신뢰도를 한 단계 낮췄습니다.
   - 이 문서, [style-guide.md](style-guide.md), [playbook.md](playbook.md)는 재검증된 계정 파일을 옮겨 반영한 것입니다. 반영 단계에서는 새 검색을 하지 않았습니다.
3. **수치의 기준일이 제각각입니다.**
   - 사용자 표(2026-09경, 정확한 촬영 시각은 모름)가 가장 최신으로 보입니다. 다만 에크케 40.4만·6,645와 BZCF 약 8만·262는 2026-09-30 검색에서 **웹 근거가 나오지 않았습니다.** 게시물 수가 늘어난 순서로 '더 나중 값'이라고 판단할 뿐입니다.
   - 검색 스니펫 수치에는 날짜가 붙어 있지 않습니다. 2026-09-30에 조회했을 때 보인 값이고, 실제보다 몇 주~몇 달 늦을 수 있습니다.
   - 채용공고 수치(AI Freaks 6.5만+, 월 조회 약 1,000만)는 회사의 **자기 주장**입니다.
4. **계정마다 검색에 잡힌 정도가 다릅니다.**
   - 에크케: 인스타와 스레드 게시물이 비교적 잘 잡힘. 재검증에서 결과 제목에 전체 표시 이름이 붙은 IG 게시물이 늘어 귀속이 더 확실해짐
   - BZCF: 인스타 캡션은 인스타를 겨냥한 재검색 5회에서도 0건. **같은 계정의 스레드 글**과 **링크드인 게시물 제목**이 주 근거
   - AI Freaks: 재검증 48회 뒤에도 이 계정 게시물로 **확정된 것이 0건**. 후보 7건 중 1건은 삼성SDS 게시물로 판명됨
   - 로만: 로만을 겨냥한 재검색 21회에서도 계정 자체가 검색되지 않음
5. 검색 도구가 미국 기준 결과를 돌려주므로 한국 결과가 덜 잡혔을 수 있습니다.

### 1-3. 근거 표기
| 표기 | 뜻 |
|---|---|
| [확인] | 출처 URL이 있고 날짜·내용이 맞음 |
| [검색 요약] | 검색 도구의 요약문에만 나오고 결과 제목으로는 확인되지 않음. 신뢰도를 한 단계 낮춤 |
| [스레드 기준] | 같은 운영자의 스레드 글에서 확인. 인스타 캡션도 같은지는 모름 |
| [자기 주장] | 회사나 운영자가 스스로 밝힌 수치 |
| [추정]·[추론] | 정황으로 판단. 직접 증거 없음 |
| [미확인] | 찾지 못함. '없다'가 아니라 '못 찾았다' |
| [제안] | 조사 결과가 아니라 제가 권하는 값 |

### 1-4. 스크린샷이 있으면 바로 보완할 수 있는 것
로그인 정보 없이 **앱 화면 스크린샷만** 있으면 됩니다. 가장 필요한 순서입니다.
1. **로만**: 프로필 상단, 그리드 25개 전체, 반응이 많은 게시물 3개의 1·2번 장과 캡션, 프로필 ⋯ → '이 계정 정보'
2. **AI Freaks**: 프로필 상단(게시물 수, 바이오), 최근 그리드 30개, 캐러셀 1편 전체, 릴스 1편 첫 화면, '#광고' 게시물 1편, 후보 게시물 URL 6개의 작성 계정([style-guide.md 2-4](style-guide.md#2-4-ai-freaks-ai_freakskr-확정-예시-없음))
3. **BZCF**: 인스타 그리드 30개(캐러셀이 있는지), 최근 게시물 3편의 캡션
4. **에크케**: '이렇게 벌고 쓴다/씁니다' 캐러셀 1편 전체(장 수, 마지막 장), 최근 그리드 30개, 플레이브 편(DJ1DD34SOdw)이 에크케 게시물인지

항목별 체크리스트는 [style-guide.md 6장](style-guide.md#6-시각-스타일-체크리스트)에 있습니다.
