## 1. 4개 계정 스타일 비교표

| 항목 | **@ai_freaks.kr** | **@bizucafe** (스레드 기준) | **@romaan.mag** | **@ekke.now** |
|---|---|---|---|---|
| **표지·훅** (캡션 첫 줄) | 근거 없음 | ① 서열 수식어 + 인물 + 콘텐츠 종류("실리콘밸리의 왕 a16z 벤 호로위츠 인터뷰.") ② 따옴표 발언 먼저("\"이거 하는 회사들에 투자하겠다\" 세계 최고 VC인 a16z 파트너들이…") ③ 감정 한 줄("미국은 무섭긴 하다.") ④ 속보 선언("또 하나의 AI유니콘 등장.") ⑤ <꺾쇠 제목> + 번호 ⑥ 출처 먼저("FT 기사 내용 중 일부.") | 게시물 0건. 바이오는 '대비 + 독자 정의' 구조 | ① 주제 이모지 + [대상]는 이렇게 벌고 씁니다 + (*기준) ② 대사 한 줄(릴스, "아 네 주임님 잠시만요 …") ③ 질문형("TJ 주주님들 이거 맞나요 …") ④ 랭킹·1위형 ⑤ '~길래' 체험형 ⑥ 예능 패러디("🏠 나 혼자 벌고 쓴다") |
| **슬라이드 구성** | 근거 없음. [추론] 제작 툴(Figma 등)로 보아 템플릿 기반 | 관찰 없음. 인스타 최근 확인분은 릴스뿐 | 미확인 | [추정] 연재 5~6장: 표지 → 소개·밈 → 수익 구조 → 실적 수치 → BUT 반전 → ⇒ 결론 (스레드 텍스트 순서 기준) |
| **캡션 구조** | 근거 없음 | 1행 훅 → 출처·형식 명시 → 번호 요점 또는 따옴표 발췌 → 1~2문장 코멘트 → '전문 : 링크' | 미확인 | [이모지] 제목 (*기준) → [이모지] 밈 소제목 → 소개 1문장 → '- ' 설명 → '· 매출) 5,766억 원(3.2%↑)' 수치 줄 → BUT → ⇒ 결론 |
| **말투** | 톤앤매너 가이드가 있음(채용공고). 실제 어미 미확인 | 해설은 '~다'("총 14개다"), 소개·공지는 '~입니다/~네요/~에요'. 띄어쓰기를 다듬지 않아 사람이 쓴 느낌. 과장 없이 담백 | 바이오는 명사형 선언문 | 제목은 합니다체('이렇게 벌고 씁니다'), 본문은 음슴체·반말('달성함', '정리해 봄', '드갑'). 팬덤·커뮤니티 어휘 |
| **화자·호칭** | 미확인 | 독자 '분', 인물 '대표님/~님', 자기 쪽 '저희 채널'(1건) | 미확인 | 브랜드 3인칭 '에크케' + '에디터' 1인칭. 독자 '주주님들'은 분명한 사례 1건뿐 |
| **이모지·해시태그** | 미확인 | 스니펫에서 거의 안 보임(잘린 글이 많아 단정 못 함) | 미확인 | 첫 글자 주제 아이콘 1개, 소제목 1개, 끝 강조 1개. 연재 해시태그(#이렇게벌고쓴다, #에크케미). 대량 해시태그는 미확인 |
| **시리즈** | 확인된 것 없음 | '<인물 + 조언>', 'OO 인터뷰 중 좋았던 것 N가지', 'OO 한글 번역입니다', 자체 인터뷰 'OOO 대표님을 모셨습니다' | 미확인 | '이렇게 벌고 씁니다' 7회, '나 혼자 벌고 쓴다', '#에크케미', '이 주의 관전 포인트' |
| **CTA** | 링크 페이지(소셜비즈)에 채용·제휴 링크. 게시물 CTA는 미확인 | '전문 : 블로그 링크', "볼 가치가 있다고 생각합니다", 댓글 이벤트. 저장·팔로우 요청은 표본에 없음 | 미확인 | 독자 호명 + "주목 ✨", 브랜드 동참 선언("오늘부터 에크케도 짠테크 드갑"), 출연자 태그. 명시적 저장·공유 요청은 캡션 첫머리에 없음 |
| **출처 표기** | 미확인 | 매체명·원저자는 적음. 원문 URL은 대체로 없고 자사 블로그로 연결 | 미확인 | 기준 연도·법인명("* 2025년 기준 / 법인명: 케이티스포츠"), 사진 출처 '📷 연합'(1건). 원문 링크 없음 |
| **광고 게시물** | 브랜디드 제작이 에디터 핵심 업무, 20곳 이상 협업(자기 주장). 표기 방식 미확인 | norda 글: "멋진 브랜드를 발견했어요 … 내돈내산 입니다" → 협업 댓글 이벤트. '#광고' 표기와 유료 여부는 미확인 | 미확인 | "#광고 💪 답답해서 내가 …": '#광고'가 첫 단어이고 말투·시간대는 편집물과 같음(1건) |
| **시각 요소** | 미확인 | 미확인. 유튜브 썸네일 담당자가 있음(HOC 인터뷰) | 미확인 | 미확인. 주제 이모지, 보도사진 사용 추정('📷 연합'), 현장 영상의 에디터 1인칭 자막 |

## 3. 공통 공식 추출

### 3-1. 첫 줄(표지) 공식: 확인된 6가지

| 공식 | 구조 | 확인된 계정 |
|---|---|---|
| **A. 고정 연재형** | [주제 아이콘] + [대상] + 고정 동사구 + (*기준) | 에크케 7회 |
| **B. 서열 수식어형** | [최상급 수식어] + [인물·기관] + [콘텐츠 종류] | BZCF(스레드) |
| **C. 따옴표 발언형** | "[핵심 발언]" + 누가 했는지 | BZCF(스레드) |
| **D. 출처 먼저형** | [매체·원저자] + '중 일부' / '번역' | BZCF(스레드) |
| **E. 대사·질문형** (릴스) | 독자가 실제로 하는 말 한 줄, 또는 호명 + "이거 맞나요" | 에크케 릴스 |
| **F. 대비 + 독자 정의형** | [흔한 방식] 대신 [내 방식]하려는 [독자] | 로만(바이오). 표지에 쓰는 것은 응용 |

### 3-2. 캡션 뼈대: 에크케와 BZCF의 공통 5단
1. **훅 한 줄**: 위 A~E 중 하나
2. **기준·출처**: 에크케는 '(*2025년 기준 / 법인명)', BZCF는 'FT 기사 내용 중 일부', '~ 번역'
3. **번호 또는 수치**: BZCF '1. 요점 - 부연', 에크케 '· 매출) 값(증감)'
4. **반전 또는 내 코멘트**: 에크케 'BUT …', BZCF 'SF 영화 같기도 하다.'
5. **결론 또는 이동**: 에크케 '⇒ 결론', BZCF '전문 : 링크'

### 3-3. 두 겹 말투
- **제목은 격식, 본문은 가볍게**: 에크케는 제목 합니다체 + 본문 음슴체입니다.
- **해설은 평서, 소통은 존댓말**: BZCF는 해설 '~다' + 소개·권유 '~입니다/~네요'입니다.
- 공통점: 제목과 본문의 말투를 **일부러 다르게** 두고, 각각은 일관되게 씁니다.

### 3-4. 약속 → 연재명 → 해시태그
- 에크케: 소개문 '벌기·쓰기' → "이렇게 벌고 씁니다" → #이렇게벌고쓴다
- 내 계정에 옮기기: 바이오의 핵심 동사를 연재명으로, 연재명을 해시태그로 만드세요(4-1의 1번 공식).

### 3-5. 이모지는 아이콘 역할만
- 에크케는 주제 아이콘 1개로 시작하고(🏭 반도체, ⚾ 구단, 🎅 산타), 소제목과 끝 강조에 1개씩만 씁니다.
- BZCF는 스니펫상 거의 쓰지 않습니다.

### 3-6. 두 계정이 하지 않는 것 = 내 차별화 기회
| 두 계정의 빈 곳 | 내 계정에서 할 것 |
|---|---|
| 원문 링크와 날짜를 대체로 주지 않음 | 마지막 장과 캡션에 **매체명·제목·날짜**를 적고, 링크는 프로필 링크 페이지나 스토리로 |
| 에크케는 매체마다 증감률이 달라 수치 오류 위험(메타코미디 편) | 수치는 **공시·보도자료 원문과 대조**하고 기준 시점을 적기 |
| BZCF 코멘트는 1~2문장 | 독창성 정책(2026-04-30) 대비로 **해설 비중을 더 크게** |
| 명시적 저장·보내기 요청이 캡션 첫머리에 없음 | 마지막 장에 **CTA 하나**(저장 / 보내기 / 댓글 키워드) |
| 광고 표기 1건만 확인 | 광고는 **이미지 안 + 캡션 첫 단어 + 유료 파트너십 라벨** 세 곳 모두 |

| 21~26초 | 에디터 한 줄 | "그래서 [직군]에게는 …" |
| 26~30초 | CTA 하나 + 시리즈명 엔드카드 | "댓글에 '[키워드]' 남기면 요약본 보내드려요" |

**B. 상황극형** (에크케 대사 한 줄 방식)

| 구간 | 화면 | 대사·자막 |
|---|---|---|
| 0~3초 | 인물 화면, 이모지 없이 대사 한 줄 | "아 네 팀장님 잠시만요…" |
| 3~15초 | 직장에서 흔한 상황 전개 | 공감 포인트 1개 |
| 15~25초 | 반전: AI로 해결하거나 정보 한 줄 | 툴 이름과 방법 한 줄 자막 |
| 25~30초 | 펀치라인 + CTA | "이 방법 궁금하면 댓글에 '[키워드]'" |

**제작 규칙** ([best-practices.md 2-2](best-practices.md))
- 자막은 필수입니다. 소리를 끄고 보는 사람이 많습니다.
- 다른 앱 워터마크를 남기지 마세요(Edits 권장). 내 목소리나 오리지널 오디오를 쓰세요.
- 같은 주제로 첫 3초만 다른 2~3안을 만들어 체험 릴스(Trial Reels)로 먼저 테스트하고, 이긴 문장을 카드 표지에 다시 쓰세요.

## 5. 톤 가이드

### 5-1. 기본 말투 고르기

| | **A. 담백 해설형** (기본값 추천) | **B. 캐주얼 밈형** |
|---|---|---|
| 참고 계정 | BZCF(스레드) + 로만의 포지션 | 에크케 |
| 표지 | 명사형·합니다체: "OO는 AI를 이렇게 씁니다" | 같음 |
| 카드 본문 | '~다' 평서 또는 개조식 명사형: "회의록 요약은 A가 가장 정확하다" | 음슴체: "요약은 A가 제일 정확함" |
| 에디터 코멘트 | '~요/~입니다': "직접 써 보니 설정이 제일 중요했어요" | 브랜드 3인칭: "[브랜드]가 정리해 봄" |
| 어울리는 포지션 | 해설형, 직군 버티컬 | 대중형, 돈·라이프스타일 |
| 주의 | 딱딱해질 수 있으니 소제목 한 줄에 위트 | 가벼워 보일 수 있고, 거친 구어는 광고주 적합성 위험 [추정] |

**추천**: A를 기본으로 하고, 에크케식 **밈 소제목 한 줄**만 빌려 오세요.

### 5-2. 화자와 호칭 (하나로 고정)
- **화자**: '에디터' 1인칭 하나로 고정합니다. 예: "에디터가 직접 써 봤습니다". 브랜드 이름은 시리즈명과 서명에만 씁니다. 에크케는 브랜드 3인칭과 에디터 1인칭을 섞는데, 처음 시작하는 계정은 하나가 낫습니다 [제안].
- **독자 호칭**: 하나로 고정합니다. 예: "[직군]님"(선생님, 기획자님). 에크케의 '주주님들'은 분명한 사례가 1건뿐이라 고정 호칭인지 알 수 없습니다. 우리는 처음부터 정해 두세요.
- **인물**
  - 해설 본문: "[소속] [직함] [이름]"(님 생략)
  - 인터뷰이: "[이름] 님", "[이름] 대표님"(BZCF 방식)

### 5-3. 위치별 어미

| 위치 | 어미 | 예 |
|---|---|---|
| 표지·캡션 첫 줄 | 명사형, 합니다체, 질문 | "그래서 뭐가 달라지나", "이렇게 씁니다" |
| 카드 본문 | '~다' 또는 명사형 종결 | "비용은 절반으로 줄었다" |
| 수치 줄 | 기호 형식 | "· 비용) 월 2만 원(50%↓)" |
| 에디터 코멘트 | '~요/~입니다' | "실제로 써 보니 한계도 분명했어요" |
| CTA | '~하세요' 권유 한 문장 | "저장해 두고 회의 전에 꺼내 보세요" |

### 5-4. 이모지·해시태그·표기 규칙
- **이모지**: 캡션 첫 줄 맨 앞에 **시리즈별로 고정한 주제 아이콘 1개**, 소제목 앞 최대 1개, 끝 강조 최대 1개. 캡션 전체 3개 이하입니다. 카드 이미지 안에는 이모지 대신 자체 아이콘을 쓰세요. 광고 게시물은 '광고'가 이모지보다 앞에 옵니다.
- **해시태그**: 최대 5개(2025-12 인스타 제한, [best-practices.md 1-6](best-practices.md)). **시리즈 태그 1개**를 고정합니다(#이렇게벌고쓴다처럼).
- **기준 시점**: "(*2026년 2분기 기준)", 법인·기관 공식 이름
- **환산**: 외화는 원화로 바꾸고 환율 기준일을 적습니다.
- **증감**: "(3.2%↑)"
- **출처**: `출처: 매체명(YYYY-MM-DD)`
- **외국 고유명사**: 첫 등장 때 "한글(영문)"

### 5-5. 금지 표현

| 종류 | 예 | 이유 |
|---|---|---|
| 과장·공포 | 무조건, 충격, 역대급, 미쳤다, 모르면 손해, 놓치면 끝, 100% | 신뢰 하락. '이해' 포지션과 충돌 |

| 근거 없는 최상급 | 최초, 유일, 1위(출처 없이) | 서열 수식어는 출처가 있을 때만(BZCF식 '세계 최고 VC'도 근거가 있는 표현) |
